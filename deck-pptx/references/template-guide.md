# 事業用スライドテンプレートの使い方

白地・明朝の見出し・細い罫線・Klein Blue（`#002FA7`）の 16:9 のテンプレート。スライドマスター 1 つ、レイアウト 20 種、編集できるサンプル 32 枚。

| 版 | 編集用 | 新規資料用 | プレビュー |
|---|---|---|---|
| ロゴあり（continova） | `assets/templates/continova-business-template.pptx` | `.potx` | `-preview.pdf` |
| ロゴなし | `assets/templates/unbranded-business-template.pptx` | `.potx` | `-preview.pdf` |

ロゴなし版は、表紙・結び・共通フッターのロゴを除き、結びの Web 欄を入力欄にしている。本文の配置・書体・配色は両版で同じ。

## ロゴと社名の扱い

ロゴあり版のロゴと社名（continova）は、このリポジトリのライセンス（MIT）の対象外。自分の資料に使うときは、ロゴなし版を使うか、ロゴを自分のものに差し替える。

ロゴの差し替え方:

1. ロゴあり版の pptx を PowerPoint で開き、「表示 → スライドマスター」を開く
2. マスターと、表紙（`01｜表紙`）・結び（`19｜お問い合わせ・結び`）のレイアウトにあるロゴの画像を選び、右クリックの「図の変更」で自分のロゴに替える
3. 結びの Web 欄の文字を直す
4. 保存した pptx を `uv run scripts/clean_template.py <保存した pptx> <出力の pptx>` に通す（ノートと、使っていない画像を外し、potx も書く）

## 基本操作（PowerPoint で直接使うとき）

1. potx を開き、新しいプレゼンテーションを pptx として保存する
2. 基本のページは「ホーム → 新しいスライド」からレイアウトを選ぶ。既存のページには「レイアウト」から当てる
3. 図解・表・ガント・体制図は、対応するサンプルのページを複製して編集する（図解そのものはレイアウトに固定していない）
4. 不要なサンプルを消し、題と本文を差し替える。サンプルの文言・記号・期間は作例
5. 写真・画面の枠は画像のプレースホルダー。枠から画像を入れる

## 全体のデザインを変えるとき

- **マスター**: 「表示 → スライドマスター」で、共通のフッター・罫線と、各レイアウトの見出し・本文の位置を変える
- **レイアウトに戻す**: 動かしたプレースホルダーは「ホーム → リセット」でレイアウトの位置に戻る
- **色**: テーマのアクセント 1 は `#002FA7`、本文は `#111111`、補助の文字は `#6F7175`。背景は白、補助面は `#F4F2EE`。淡い青・罫線などの一部は図形に直接指定している
- **書体**: 見出しはヒラギノ明朝 ProN、本文はヒラギノ角ゴシック。書体は埋め込んでいない。Windows など書体の無い環境では、テーマの書体か「フォントの置換」で游明朝・游ゴシックなどに替え、改行を確かめる

## 制作の決まり

- 左上の小さな英語の章・型のラベルと、左下の Confidential は置かない
- 型は「伝えたいこと → 情報の関係 → 項目数・説明量」で選ぶ（`type-map.md`）。分析の図は Plotly などで作って貼ってよく、テンプレートでは図と説明の配置をそろえる
- 抽象的な説明は、工程・入出力・階層・対応関係・循環など、中身に合う図と具体例で補う。意味の無い装飾や、実際には無い因果・順序を図で足さない
- 見せ方の候補があるページは、同じ中身で 2〜3 案を同じ pptx に置き、伝わりやすさ・使う場面・推す理由を添えて依頼者に選んでもらう

## テンプレートを改訂するとき

1. pptx を PowerPoint で直す
2. `uv run scripts/clean_template.py <直した pptx> assets/templates/<版>-business-template.pptx` で掃除して置く（potx も書く）
3. プレビューの PDF を書き出し直す: `soffice -env:UserInstallation=file://$(mktemp -d) --headless --convert-to pdf <pptx>` の出力を `<版>-business-template-preview.pdf` にする（別のプロファイルで動かす。使用中のプロファイルがあると、何も出さずに失敗する）
4. `scripts/selftest.sh` を通す（ロゴなし版にロゴの画像とノートが無いことも確かめる）
5. サンプルの題を変えたら `type-map.md` と `references/example-build.py` を直す
