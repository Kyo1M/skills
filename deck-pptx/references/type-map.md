# 型の対応表

構成 md の図版指示に書かれた型（`html-slide-deck/references/slide-patterns.md` の型の名前）を、テンプレートのどれで受けるかの表。受け方は 3 通り。

| 受け方 | 使う場面 | 書き方 |
|---|---|---|
| サンプル | 図形の組み方が込み入った型。位置をコードで書き直すより作例を写すほうが崩れない | `T.duplicate(prs, T.find_sample(prs, "<題>"))` で複製し、`P.replace_paras(P.shape(s, <ID か名前>), [...])` で文言を差し替える。図形の ID と名前は `template.py --inspect unbranded --page <N>` で見る |
| レイアウト | 項目数で形が変わる型 | `T.new_slide(prs, "<番号>", 題, リード文)` で足し、`T.body_area(s)` の範囲に部品を置く |
| 写す | 再掲・流用のページ | 前回の資料のページを `T.duplicate` するか、別の資料から `T.import_slide` で写す |

サンプルページは番号でなく題で指す（題の照合は空白・改行を除く）。テンプレートを改訂してページが増減しても対応がずれない。

## 項目数が作例と合わないとき

- **作例より少ない**: 使わない組の図形を `P.delete` で外し、残りの位置はそのままにする（間を詰めると作例の釣り合いが崩れる）。2 列の作例で 1 項目だけ残るときは、レイアウト＋部品で描き直す
- **作例より多い**: 作例を伸ばさず、上の表の「超えたとき」の部品に替える
- 合う型が無いページは、骨格（流れ・対比・階層・並列）を部品の組み合わせで描き、骨格の無い軽い共有だけ箇条書きにする（html-slide-deck と同じ決まり）

## 前回の資料から始めるとき

前回の資料にサンプルページは無い。同じ型の前回のページを `T.duplicate` で複製し、`T.strip_body` で枠だけ残してから、上の表の部品を置く。前回のページの文言を差し替えるだけで済む型（表紙・章扉・振り返りなど）は、`P.replace_paras` と `P.rebuild_table` で書式を保って差し替える。
