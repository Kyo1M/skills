# 研究者向けの型

共同研究者・査読者に渡すレポート。手法を式で定義し、単体で読んで分かる物語にする。

## 既定: self-contained の物語型

notebook の問い（Q1／Q2／Q3）をそのまま写さず、単体で読んで分かる物語に組み立て直す。

構成: 概要（物語・具体の数字）→ 背景・課題・目的 → 方針 → 実施 → 結果（図が中心）→ まとめ・今後（簡潔な文と箇条書き）→ 末尾に再現情報

- **本文は言葉と数字と図を主体にする**。要点の式は本文に載せてよいが、導出の過程・複雑になった式・重い診断は削るか付録に送る。付録に送る場合も「付録に回す」と本文に書かず、本文だけで背景 → 方針 → 実施 → 結果 → まとめが追えるようにする
- **抽象的な概念は実数とグラフで示す**（経験分布の実際の件数、分布の図など）。数式だけで説明しない
- **概要は具体の数字入りの地の文で書く**: 課題 → 目的 → これまで → 残る課題 → アプローチ → 方針を一言 → 結果を一言
- **冗長に書かない**。考察・まとめは簡潔な文と箇条書き。総合解釈・妥当性・限界・結論は「まとめ・今後」にまとめてよい
- **まとめは「やったこと → 結果」を軸に書く**。限界は必須でない。懸念があれば「まとめ・今後」の地の文に溶かし、限界の羅列でまとめを膨らませない
- 比較の相手はランダムなどのベースラインにする。前の版との差分は、単体で完結するなら載せない
- **記号と指標は定義してから使う**。結果に効く手法上の選択（正規化・重み・温度など）は本文で開示し、定数は値だけでなく出所（どう決めたか）を 1 文添える。要約の指標（相関・一致度）とモデルのパラメータに同じ文字を使い回さない
- 要旨は達成だけでなく、目標に届かない点も率直に運ぶ（「やや高め」などで実質の差を薄めない）
- 冒頭のカード型の数値表示は使わない。主要な数値は概要の文章と小さな表で示す

## 手法の説明（数式の出し方）

1. **手法の章は目的関数（対数尤度など）の全体式から始める**。成分ごとの詳細はその後。読者はまず「何を最大化・最小化しているのか」を 1 つの式で見たい
2. **モデルを言葉だけで指さない**。「モデルどおりに回すと」では、どのモデルか分からない。短く書けるなら括弧書きでよいので本文に式を出す。ベースラインと採用した手法で式が違うなら、両方を式で示し、違いを明記する
3. **説明を後の章へ先送りしない**。「なぜこの定数が要るかは §4 で述べる」と引っ張らず、読者が疑問を持つその場で要点を答える（詳しい実測は後段でよい）
4. **因果は「原因は〜にある」で終わらせない**。メカニズム、使った用語の定義、その対処がなぜ妥当か、の 3 つがそろって初めて説明になる。数値で示せる部分は数値を添える

## 学術論文の体裁が要るとき

既定は上の物語型。体裁が要るときだけ次の章立てにする。

概要 → 背景 → データ → 手法（記号表と導出を本文に）→ 結果 → 考察 → 妥当性 → 限界 → 結論 → 参考文献 → 付録

- 用字（漢字・かなの使い分け）は規約に従う

## チェック

- [ ] 手法の章が目的関数の全体式から始まっているか（成分の詳細より先に、何を最大化しているかを 1 式で示したか）
- [ ] 「モデル」を言葉だけで指していないか（どのモデルかを式で定義したか。ベースラインと採用した手法の式の違いを書いたか）
- [ ] 説明を後の章へ先送りしていないか
- [ ] 因果の説明に、メカニズム・用語の定義・対処の妥当性がそろっているか
- [ ] 本文が付録なしで追えるか
