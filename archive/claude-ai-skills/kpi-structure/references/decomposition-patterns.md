# KPI分解パターン集

代表的なKGIに対するロジックツリー分解パターン。

## 売上高（Revenue）

```
売上高
├── 顧客数
│   ├── 新規顧客数
│   │   ├── リード数
│   │   └── リード→顧客CVR
│   └── 既存顧客数
│       ├── 前期顧客数
│       └── 継続率（1 - Churn Rate）
└── 顧客単価（ARPU）
    ├── 購入頻度
    └── 1回あたり購入単価
        ├── 購入点数
        └── 商品単価
```

## MRR（Monthly Recurring Revenue）

```
MRR
├── 新規MRR
│   ├── 新規契約数
│   └── 平均契約単価
├── 拡大MRR（Expansion）
│   ├── アップグレード数
│   └── アップグレード単価増分
├── 縮小MRR（Contraction）
│   ├── ダウングレード数
│   └── ダウングレード単価減分
└── 解約MRR（Churn）
    ├── 解約数
    └── 解約顧客の平均単価
```

**派生指標**
- Net MRR = 新規MRR + 拡大MRR - 縮小MRR - 解約MRR
- ARR = MRR × 12

## LTV（Life Time Value）

```
LTV
├── ARPU（顧客単価/月）
│   ├── 基本料金
│   └── 追加課金額
└── 平均継続期間（月）
    └── 1 / 月次Churn Rate
```

**別分解**
```
LTV = ARPU × 粗利率 × 継続期間
```

## MAU（Monthly Active Users）

```
MAU
├── 新規ユーザー
│   ├── 流入数（チャネル別）
│   │   ├── Organic
│   │   ├── Paid
│   │   └── Referral
│   └── 登録CVR
├── 復帰ユーザー
│   ├── 休眠ユーザー数
│   └── 復帰率
└── 継続ユーザー
    ├── 前月アクティブ数
    └── 継続率
```

## DAU / WAU

```
DAU
├── 新規（当日登録＋利用）
├── 継続（前日もアクティブ）
└── 復帰（前日は非アクティブ）
```

**関連指標**
- DAU/MAU比率（Stickiness）
- WAU/MAU比率

## Churn Rate（解約率）

```
月次Churn Rate = 当月解約数 / 月初顧客数

解約数
├── 自発的解約
│   ├── 価値不満
│   ├── 価格不満
│   └── 競合乗り換え
└── 非自発的解約
    ├── 決済失敗
    └── アカウント停止
```

## CVR（Conversion Rate）

```
全体CVR
├── ステップ1 CVR（認知→興味）
│   └── LP訪問 / 広告表示
├── ステップ2 CVR（興味→検討）
│   └── 詳細閲覧 / LP訪問
├── ステップ3 CVR（検討→購入）
│   └── カート追加 / 詳細閲覧
└── ステップ4 CVR（カート→完了）
    └── 購入完了 / カート追加
```

## EC GMV（Gross Merchandise Value）

```
GMV
├── 注文件数
│   ├── 訪問者数（UU）
│   │   ├── 新規訪問
│   │   └── リピート訪問
│   └── 購入CVR
│       ├── カート投入率
│       └── カート完了率
└── 平均注文単価（AOV）
    ├── 平均購入点数
    └── 平均商品単価
```

## 広告事業 Revenue

```
広告売上
├── インプレッション数
│   ├── PV / UU
│   └── 広告表示率
├── CTR（クリック率）
└── CPC / CPM
```

**別分解（ARPU型）**
```
広告売上 = MAU × ARPU
ARPU = セッション数/人 × PV/セッション × 広告単価/PV
```

## アプリ事業

```
アプリ売上
├── 課金ユーザー数
│   ├── アクティブユーザー数
│   └── 課金率
└── ARPPU（課金者単価）
    ├── 課金頻度
    └── 1回あたり課金額
```

## BtoB SaaS

```
ARR
├── 新規ARR
│   ├── リード数
│   ├── 商談化率
│   ├── 受注率
│   └── 平均契約単価
├── 拡大ARR
│   ├── アップセル
│   └── クロスセル
└── 解約ARR
    ├── Logo Churn（社数）
    └── Revenue Churn（金額）
```

**効率指標**
- CAC（Customer Acquisition Cost）
- CAC Payback Period = CAC / (ARPU × 粗利率)
- LTV/CAC比率（目安: 3以上）

## 分解のコツ

1. **掛け算で分解**: 率 × 量 の形が施策を考えやすい
2. **足し算で分解**: セグメント別（新規/既存、チャネル別）に分ける
3. **ファネルで分解**: 顧客行動のステップごとに分ける
4. **時間軸で分解**: 期間 × 頻度 の形にする
