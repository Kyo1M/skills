# note記事作成支援スキル

新規事業開発・MVP開発に関するnote記事を、クリティカルな視点でレビューし、改善版を作成する。

## 対話フロー

```
1. ユーザーが下書き/アイデアを投稿
2. 確認質問（5項目以内）
3. クリティカルレビュー（忖度なし）
4. ユーザーが方向性を承認
5. 改善版を作成（画像プロンプト含む）
```

## Step 1: 確認質問

下書きを受け取ったら、以下を確認する。既に明らかなものは省略。

- **ターゲット読者**：誰に読んでほしいか（例：スタートアップ創業者、企業の新規事業担当）
- **記事の目的**：読者に何をしてほしいか（例：サービスに興味を持つ、考え方を知る）
- **想定ボリューム**：長め（3,000字超）か、コンパクト（2,000字以下）か
- **画像の制作方法**：AI生成か、自作か
- **その他の制約**：シリーズ記事の一部か、単発か

## Step 2: クリティカルレビュー

レビュー観点の詳細は `references/review-checklist.md` を参照。

### レビューの原則

- **忖度しない**：良くない部分は明確に指摘
- **建設的である**：問題だけでなく改善案を提示
- **優先順位をつける**：致命的な問題を先に指摘

### レビュー構成（この順で提示）

1. **致命的な問題**（あれば）：読者が離脱する、または誤解を招く問題
2. **構造的な問題**：導入が長い、論理の飛躍、ターゲットのズレなど
3. **言葉の問題**：刺さらない表現、専門用語の乱用など
4. **改善後の構成案**：章立てと想定文字数

## Step 3: 改善版の作成

### 記事のフォーマット

- **文字数**：本文のみで2,500〜3,500字を目安（画像プロンプトは文字数に含めない）
- **見出し**：H2（##）とH3（###）のみ使用
- **太字**：重要なメッセージに限定（1段落に1箇所以下）
- **リンク**：外部リンクは必要最小限

### 箇条書きと長文の使い分け

**箇条書きを使う場面**
- 複数の要素を並列で列挙するとき（例：3つの条件、5つのステップ）
- 比較や対比を明確にしたいとき
- チェックリスト的な情報を整理するとき

**長文で書く場面**
- 概念や背景の説明：読者が「なぜそうなのか」を理解できるよう、文脈を丁寧に説明する
- 具体例の紹介：状況設定→問題→解決の流れを物語的に書く
- 著者の考えや主張：箇条書きではなく、論理の流れを文章で示す

### 各セクションの記述量目安

| セクション | 目安 | 書き方のポイント |
|-----------|------|-----------------|
| 導入（リード文） | 200〜300字 | 読者の課題に共感し、記事を読むメリットを示す |
| 問題提起・背景 | 400〜600字 | 「なぜこの話題が重要か」を丁寧に説明 |
| 本論（各H2セクション） | 500〜800字/セクション | 主張→理由→具体例の流れで厚みを持たせる |
| 具体例・事例 | 300〜500字 | 状況を描写し、読者がイメージできるように |
| まとめ・CTA | 150〜250字 | 要点を再確認し、次のアクションを促す |

### よくある「さっぱりしすぎ」の原因と対策

1. **理由の省略**：「〇〇が重要です」で終わらず、「なぜなら〜だからです」まで書く
2. **具体例の不足**：抽象的な説明の後に、必ず1つは具体的なシーンを描写する
3. **読者への語りかけ不足**：「〇〇と感じたことはありませんか？」など、読者を巻き込む表現を入れる
4. **段落が短すぎる**：1段落は3〜5文（100〜200字）を目安に、1文で終わらせない

### 画像の挿入

記事内に3〜6枚の画像を想定し、挿入位置に画像プロンプトを記載する。

画像スタイルは `references/image-prompts.md` を参照。

基本スタイル：コンサルスライド風（白背景、青とグレー基調、日本語テキスト入り）

### 出力形式

Markdownファイルとして出力。画像プロンプトは以下の形式で差し込む：

```
---

【画像N：〇〇の図】

■ 画像生成プロンプト（日本語）

スタイル：コンサルティングスライド風、PowerPointスライド、シンプル、ミニマル、フラットデザイン、白背景

構成：
- （図の構成要素を箇条書き）
- 重要な箇所は**太字**または赤字で強調
- ポジティブな要素は緑のアクセント

配色：青とグレー基調、アクセントに緑
アスペクト比：16:9
テキスト：日本語で記載

■ English prompt for AI tools
Consulting slide style, PowerPoint slide, simple, minimalist, stylish, clean, flat design, white background, blue and gray color scheme, green accents, Japanese text, aspect ratio 16:9, [specific diagram description]

---
```

## noteプラットフォームの考慮事項

- **冒頭3行が勝負**：スマホでは最初の3行しか見えない。ここで読者を掴む
- **目次機能**：H2見出しが自動で目次になる。見出しは端的に
- **スキマ読み対策**：見出しと太字だけで要点が伝わるように
- **OGP画像**：記事のサムネイルは別途考慮（本スキルでは扱わない）
